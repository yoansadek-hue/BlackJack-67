# Blackoff

Le blackjack simple, en solo ou en ligne avec tes amis.

- Modes : Solo, Entraînement, Partie rapide (en ligne), Avec des amis (jusqu'à 4 joueurs)
- Boutique, amis, profil, réglages, connexion Google avec sauvegarde dans le cloud
- Site statique : aucun serveur à gérer (jeu en ligne via PeerJS, comptes via Firebase)

Fichiers : `index.html`, `css/style.css`, `js/` (app, table, engine, net, auth, store, util, config), `icons/`.
